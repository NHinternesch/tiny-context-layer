# Tiny Context Layer

From zero to tiny context layer. Minimal personal context for LLMs. Small always-on core with on-demand knowledge map of external sources. No duplications. Plain markdown. For [humans](https://nhinternesch.github.io/tiny-context-layer/) and [agents](https://nhinternesch.github.io/tiny-context-layer/llms.txt).

**Private by default.** The context layer lives in the browser's local storage until it is exported.
