# Tiny Context Layer

From zero to context layer. Minimal personal context for LLMs. A small always-on core with a knowledge map of external on-demand sources. No duplications. Plain markdown. For [humans](https://nhinternesch.github.io/tiny-context-layer/) and [agents](https://nhinternesch.github.io/tiny-context-layer/llms.txt).

**Private by default.** The context layer lives in the browser's local storage until it is exported.
